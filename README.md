# Algoritma dan Pemrograman

Repository pembelajaran pendamping mata kuliah **Algoritma dan Pemrograman**, khususnya untuk mahasiswa semester 1 yang sedang mempelajari dasar-dasar algoritma dan pemrograman.

Repository ini dibuat sebagai tempat belajar tambahan bagi teman-teman yang ingin mengulang materi perkuliahan, memahami konsep yang belum dipahami di kelas, atau mencoba contoh kode secara mandiri.

Materi disusun berdasarkan urutan pertemuan kuliah dan akan diperbarui secara bertahap mengikuti materi yang sudah dipelajari bersama dosen.

## Tujuan Repository

Repository ini bertujuan untuk:

- Membantu mahasiswa memahami kembali materi perkuliahan dengan penjelasan yang lebih sederhana.
- Menyediakan contoh dan ilustrasi untuk mempermudah pemahaman konsep.
- Memberikan contoh kode program yang dapat dipelajari dan dicoba secara mandiri.
- Membantu mahasiswa berlatih menyusun logika dan menyelesaikan masalah menggunakan algoritma.
- Menjadi referensi belajar tambahan di luar kegiatan perkuliahan.

## Bahasa Pemrograman

Repository ini berfokus pada pembelajaran algoritma dan penerapannya dalam pemrograman.

- **C++** — digunakan dalam contoh implementasi program.
- **Python** — dapat ditambahkan pada materi berikutnya sesuai kebutuhan pembelajaran.

Tidak semua pertemuan harus memiliki kode program. Jika materi lebih berfokus pada teori atau konsep, penjelasan, tabel, ilustrasi, dan contoh kasus akan digunakan sesuai kebutuhan.

## 🧑‍💻 Cara Menggunakan Repository

1. Pilih folder pertemuan yang ingin dipelajari.
2. Buka file `README.md` untuk membaca penjelasan materi.
3. Pelajari contoh, tabel, dan ilustrasi yang tersedia.
4. Jika terdapat file kode program, buka file tersebut menggunakan Visual Studio Code atau editor kode lainnya.
5. Jalankan program, ubah beberapa bagian kode, dan amati hasilnya.
6. Kerjakan latihan pemahaman untuk menguji kemampuanmu.

## 🛠️ Perangkat yang Digunakan

Untuk mempelajari materi teori, kamu cukup menggunakan browser untuk membuka repository ini.

Untuk mencoba kode C++, kamu dapat menggunakan:

- Visual Studio Code.
- Compiler C++, seperti GCC atau MinGW-w64.

Petunjuk instalasi compiler dapat ditambahkan sesuai kebutuhan pada materi praktik.

## Belajar Bersama

Jangan hanya membaca dan menyalin kode. Cobalah memahami fungsi setiap instruksi, mengubah input, mengamati output, dan mencari tahu mengapa program menghasilkan hasil tertentu.

Jika masih belum memahami suatu materi, ulangi penjelasannya dan coba kerjakan latihan yang tersedia.
